# New-user home skeleton

`install` copies `home/` into `/etc/skel` without deleting distribution or
administrator files. Both host Plasma/Wayland accounts and VM XFCE/Xorg
accounts use the same skeleton. Desktop-specific files are harmless outside
their desktop, and XFCE/VM autostarts declare `OnlyShowIn=XFCE`.

The payload contains deliberate user preferences, including the repository's
Git identity. It does not contain caches, clipboard history, Plasma activity
databases, display topology, libvirt state, session state, or other files
generated by a graphical login.

Distribution branding is not copied here. Plasma obtains openSUSE branding
from system KConfig defaults in `/etc/xdg` and themes under `/usr/share/plasma`.
The skeleton does not force `GTK_THEME`, so GTK applications in Plasma retain
the distribution's KDE/GTK integration. XFCE obtains packaged themes, icons,
backdrops, and desktop data under `/usr/share`; its per-user panel, power, and
appearance choices in this skeleton intentionally override `/etc/xdg/xfce4`.

On openSUSE Tumbleweed, `useradd` combines vendor files from `/usr/etc/skel`
with administrator overrides in `/etc/skel`. On Ubuntu, `/etc/skel` itself
contains the vendor seed. The installer intentionally does not use `--delete`,
so unmanaged paths survive; managed same-path files are deliberately replaced.
